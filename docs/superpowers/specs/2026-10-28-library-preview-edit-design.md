# 라이브러리 미리보기 · 고쳐서 추가

## 목적

라이브러리(GO2 블록) 동작을 목록·타임라인에 넣기 전에 3D로 미리 보고, 필요하면 자세를 조금 고친 클립으로 목록에 넣는다.

## 확정 사항 (사용자)

- 미리보기는 라이브러리 블록 **우클릭 메뉴**(넣을 위치·목록 추가와 같은 메뉴) 맨 위 `미리보기`로 연다.
- 미세 수정 방식은 **A안: 기존 클립 편집 모드 재사용**. 미리보기 창 안에 따로 편집기를 만들지 않는다(B안 — 프로젝트 밖 클립 전용 편집 대상·실행취소·잠금을 새로 만들어야 해서 범위·위험이 큼).
- 새 클립 이름 = `<블록 이름>_수정`(같은 이름이 있으면 `_수정_2`…). 사용자가 규칙을 따로 정하지 않아 권장안 적용.

## 범위 밖

- 미리보기 창 안에서 바로 고치기(B안), 이름 직접 입력, G1 라이브러리(라이브러리는 GO2 블록뿐).

## 1. 라이브러리 미리보기

- 스토어 `blockPreview: { blockId, value, clip } | null`(화면 상태, 저장·실행취소 없음, 프로젝트를 열면 null).
  `clip`은 `previewClip(block, template, value)`로 **항상 새로 만든** 블록 클립(목록의 같은 이름 클립을 쓰지 않음), id = `BLOCK_PREVIEW_ID`(`library-preview`).
- 창: 로봇 프리뷰 줄의 마지막 칸 `라이브러리 미리보기 · <클립 이름>`, ✕ 닫기. `Stage compareClipId={BLOCK_PREVIEW_ID}` — 비교 창과 같은 자기 시계 반복, `Stage`는 그 id면 프로젝트 대신 `blockPreview.clip`을 쓰고 `blockPreview`가 바뀌면 다시 그림.
- 값 블록(Rotate·Move)은 설정 칸에서 고른 값(없으면 최저 값). 설정 칸 값이 바뀌면 미리보기도 그 값으로(`LibraryList` effect). 다른 블록을 `미리보기` = 같은 창이 그 블록으로. 창 key = 클립 이름 → 블록·값이 바뀌면 처음부터 재생.
- 프로젝트·목록·타임라인·저장·실행취소·`•` 표시에 영향 없음. `⇄ 비교`(최대 2개)와 별개.

## 2. 고쳐서 추가 (A안)

- 미리보기 창 제목줄 `고쳐서 추가` → `editPreviewAsClip()`:
  1. `{ ...blockPreview.clip, id: 새 UUID, name: '<이름>_수정' }`을 `addClipAsset`(중복 이름은 `addUniqueClip`이 `_2`…) — 실행취소 1번.
  2. 미리보기 창 닫기, `openClipEdit(새 id)`, `clipEditDraft = 새 id`.
- 클립 편집 모드(기존 기능 그대로): 메인 3D 기즈모·관절 패널·구간 수정·원본 보기·겹쳐 보기·CSV 저장. 고친 내용은 그 클립의 수정 층(`Clip.offset`), 블록 원본 채널은 그대로.
- 편집 바 `추가 취소`(`clipEditDraft === clipEdit`일 때만) → `cancelDraftClip()`: 클립 편집을 나가고 `deleteClip`(실행취소로 되돌릴 수 있음, 되돌리면 목록에 다시 생기고 편집 모드는 아님).
- `시퀀스로`(Esc)로 나가면 `clipEditDraft = null` → 보통 목록 클립. 타임라인에 끌거나 우클릭으로 넣으면 됨.
- `clipEditDraft`는 클립 편집을 나가거나 그 클립이 사라지면(`keepClipEdit`) null, 프로젝트를 열면 null. 저장 안 함.
