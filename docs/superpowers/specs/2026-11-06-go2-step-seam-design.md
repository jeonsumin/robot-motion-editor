# GO2 블록 경계 개선 1단계: 발 걸음 이음매

- 날짜: 2026-11-06
- 상태: 승인됨(사용자), 구현됨 — 수정변동사항.md §19
- 기반: `2026-10-19-go2-seam-blend-design.md`(이음매 보정)

## 1. 목적

GO2 행동 블록을 프레임 단위로 이어 붙일 때, 경계에서 이음매 보정이 관절 각도만 섞어 **디딘 발이 바닥을 미끄러지는** 문제를
스튜디오 안에서 막는다. 노래 길이에 맞춘 안무 에디터이므로 **시간은 늘리지 않는다**(사용자). 시간을 늘리는 해결(전이 조각,
기본서기 경유)은 사용자가 고를 때만.

## 2. 확정 사항 (사용자)

- 기본은 시간 유지. 시간 추가는 우클릭 메뉴 선택지로만, 자동으로는 절대 안 함.
- 조건은 실기 녹화 수준(제안 조건): 관절 속도 ≤ 0.8 × 모터 한계, 관절 가속 hip 120 · thigh 170 · calf 300 rad/s²,
  발이 떠 있는 시간 ≥ 0.2초, 발이 목표에 1 cm 안, (한 발씩일 때) 무게중심이 디딘 세 발 안 1 cm 여유.
- 조건을 못 맞추면 고치지 않고 표시(주황). 한계를 넘겨 가며 억지로 고치지 않음.
- 기본서기 = (0, 0.8, −1.5) × 4. 직접 연결이 물리적으로 안 될 때의 대안.
- 프로젝트 기본값(기본 꺼짐) + 경계마다 켜기 / 끄기 / 기본값 따르기.

## 3. 자동 처리 (`src/model/transition.ts`)

경계 = GO2 조각 B가 같은 트랙의 GO2 조각 A 끝 프레임 바로 다음에서 시작(이음매 보정 경계). 판정 순서:

1. 스위치 꺼짐 → 아무것도 안 함(지금과 같음).
2. A 끝 프레임과 B 첫 프레임이 같음(Go2 에디터 블록, S7) → 이음매 보정 없이 바로 이음. 상태 `same`.
3. 바닥에 닿은 발 수가 다름 → `lift`(빨강), 경계에 바닥 발 없음 → `air`(빨강). 표시만.
4. 계획: A 끝·B 시작에서 네 발이 서 있는(발 속도 < 2 mm/프레임) 프레임 안에 발 옮기기 창을 둠.
   - 창 끝 후보 = B 시작 후 20/36/48/60 프레임(B가 서 있는 프레임까지), 창 시작 후보 = 0 / A 정지 구간 절반 / 전부.
   - 3 cm 넘게 옮길 발: 대각 두 발씩(FR+RL, FL+RR) 차례로, 들기 = clamp(0.3 × 거리, 2, 5 cm), 수평 이동은 스윙의 15~85 %에서만.
   - 3 cm 이하 발: 들지 않고 창 전체(≥ 12프레임)에 걸쳐 5차 곡선으로 맞춤.
   - 이음매 보정이 미치는 B 앞 프레임까지 다리를 IK로 풂(발 목표 = 각 조각 자신의 발, B가 스스로 걷는 발은 그대로).
   - 몸통(루트)은 건드리지 않음 → 이어붙이기·몸통 경로 그대로. 그래서 자동에서는 한 발씩(몸통 기울이기 필요)을 쓰지 않음.
5. 조건을 모두 만족하는 후보 중 max(속도비/0.8, 가속비)가 가장 작은 것 → `ok`(초록). 없으면 `fail`(주황, 가장 가까운 후보의 이유).

결과는 프레임별 관절값으로 `itemClip`이 A·B 위에 얹는다(`seamedClip` = 지금까지의 이음매 보정 결과, `boundaryStep` = 상태와
관절값). 한 조각을 앞·뒤 경계가 같이 쓰면 앞 경계 우선(뒤 경계는 그 뒤 프레임만). 같은 두 조각의 같은 만남은 내용 해시로
다시 계산하지 않음.

## 4. 수동 전이 조각 (`src/model/bridge.ts`, `insertBridge`)

- `전이 조각 넣기`: A 끝 자세 → B 첫 자세(이어붙이기로 놓일 자리)를 잇는 새 조각.
- `기본서기 경유 넣기`: A 끝 → 기본서기(A 발 가운데 위) → 기본서기(B 발 가운데 위) → B 첫 자세.
- 몸통은 5차 곡선으로, 발은 한 발씩(들기 전에 디딘 세 발의 내심 쪽으로 몸통 최대 6 cm) 또는 대각 두 발씩.
  길이 36/60/90/120/150/180 프레임 중 조건을 만족하는 가장 짧은 것. 못 만들면 메뉴 항목 꺼짐 + 이유.
- 넣으면 B와 뒤 조각이 그 길이만큼 밀림. 메뉴에 미리 `뒤 조각 N초 밀림`. 실행취소 한 번.

## 5. 화면

- 조각 막대 시작의 색 표시: 초록 · 주황 · 빨강 · 회색. 레인 도움말에 상태 문구.
- 조각 우클릭 메뉴: `발 걸음 이음매 (이 조각 시작)` 상태·이유, `켜기 / 끄기 / 기본값 따르기 (켜짐|꺼짐)`, 수동 전이 조각 2개,
  `발 걸음 이음매 기본값 (프로젝트)`. 메뉴가 창 밖으로 나가면 안쪽으로 옮겨 띄움.

## 6. 저장

- `Item.step?: boolean`(없으면 프로젝트 기본값), `Project.stepSeam?: true`(없으면 꺼짐). 잘못된 `step`은 파일 거부, 잘못된
  `stepSeam`은 꺼짐으로 읽음.
